Snowball stemmers in memory-kit
===============================

These files are generated from the Snowball project (https://snowballstem.org/) and are
distributed under the Snowball license below (BSD 3-clause):

  system/lang/snowball-base.mjs   javascript/base-stemmer.js, unchanged
  system/lang/cs/stemmer.mjs      generated from algorithms/czech.sbl
  system/lang/en/stemmer.mjs      generated from algorithms/english.sbl (Porter2)

Source: https://github.com/snowballstem/snowball, Snowball 3.1.1,
commit 411550ddb8ea049bc3e8d39bf56454e8a9ef0be6.

Changes made for memory-kit (the stemming code itself is unchanged): a header comment, the base
class is imported from ../snowball-base.mjs, the generated class is named, and each stemmer
module adds `export function stem(word)` (also the default export). Both stemmers reproduce the
official test vocabularies exactly (snowball-data: czech/voc.txt and english/voc.txt, 0
mismatches).

Regenerating (keep the changes above):

  git clone https://github.com/snowballstem/snowball.git && cd snowball
  make snowball
  make js_out/base-stemmer.js js_out/czech-stemmer.js js_out/english-stemmer.js

Adding a language pack with a Snowball stemmer follows the same steps: generate
js_out/<algorithm>-stemmer.js, save it as system/lang/<code>/stemmer.mjs with the same changes,
and set "stemmer": "<code>" in its pack.json.
